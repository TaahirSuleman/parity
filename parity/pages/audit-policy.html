How Parity audits a page you choose

Parity compares what a sighted visitor sees on a page with what a screen-reader user is told, and shows the evidence for each gap it finds. This page says what it does on a page it does not serve, what it keeps, and whom to write to.

What Parity does on your page

  • It reads the page as a visitor would, in a headless browser, from the address a visitor typed into the workbench.
  • It never submits a form, never signs in, never types into password, card, email or phone fields, and never clicks anything that looks like paying, ordering, subscribing or deleting. Code decides this before any action runs; a model cannot talk its way past it.
  • It honours robots.txt: a page it disallows is not fetched. Cookie banners are never accepted on the visitor's behalf.
  • It makes one run per origin at a time, waits a second between page loads, and identifies itself as Parity/<version> with a link to this page in its user agent.
  • It proposes no changes to a page it does not serve. Its findings are evidence for a person to read, not a verdict on the page or its owner.

What is kept, and for how long

  • A screenshot of the audited screen, its accessibility tree, the axe-core results and the findings, for __RETENTION_HOURS__ hours. They are visible only to whoever holds the run link; nothing is listed anywhere.
  • After __RETENTION_HOURS__ hours every file holding page content is deleted. A small summary stays: the site's origin, the outcome, the counts, the cost and the time, so the day's spending can be checked.
  • Nothing from a page a visitor chose enters Parity's public samples or its evaluation.
  • The visitor affirms, before a run starts, that the page is public and that they may audit it; the time of that affirmation is stored with the run.

Opting out, and takedown

If you would rather Parity did not read your site, write to __CONTACT__ and the host joins the deny list; every later request for it is refused with "This site asked not to be audited." The same address handles a takedown: name the run link or the site, and the run's content is deleted ahead of the __RETENTION_HOURS__-hour limit.

Limits

Each run has a cost ceiling and a time limit, each origin has a few runs a day, and the field closes for the day when its budget is spent. Sites behind bot challenges or logins end the run early, and the workbench says so.

Parity is a hackathon project. Its findings are evidence to read, never a claim about a page's standing under any rule.
